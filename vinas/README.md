# Logos de viñas partners

Sube aquí los logos tal como los tengas (PNG, JPG, SVG o PDF), uno por viña.
Nombra cada archivo con el nombre de la viña, por ejemplo: `lof.png`, `perez-cruz.jpg`.

Claude los procesa para la web:
1. Quita el fondo (queda transparente).
2. Los lleva a un mismo color (crema de la marca) para que se vean como un set.
3. Mejora la definición de los que estén borrosos o pequeños.

Consejo: si la viña tiene el logo en su sitio web en SVG o PNG grande, ese es el mejor original.
