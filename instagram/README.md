# Fotos para la galería de Instagram de la web

Sube aquí entre 6 y 9 fotos cuadradas **1080x1080** (JPG o WEBP), con nombres en orden:
`ig-01.jpg`, `ig-02.jpg`, … `ig-09.jpg`.

El orden del nombre es el orden en la grilla (de izquierda a derecha, de arriba abajo).
Claude las pasa al tema de Shopify; después se pueden cambiar desde el editor
(sección **MT · Galería Instagram**, cada foto tiene su selector de imagen).
